# HomjeeVendor — Expo Migration

This project was migrated from React Native CLI (RN 0.80.1) to **Expo SDK 54 (Bare Workflow)**.

The `android/` and `ios/` folders are **generated** by `npx expo prebuild` and should not be edited by hand — native configuration lives in `app.json`.

## Why Bare Workflow (with Dev Client)

The app uses `react-native-date-picker`, a native module that is **not** available in Expo Go. A custom dev client is required. All other native-affecting config (permissions, icons, splash, fonts, package name) is declared in `app.json` so continuous native generation (CNG) works.

## Prerequisites

- Node.js >= 18
- JDK 17
- Android Studio with Android SDK, `ANDROID_HOME` set
- (iOS only) Xcode + CocoaPods

## First-time setup

```bash
# 1. install JS deps
npm install

# 2. generate native android/ios projects from app.json
npx expo prebuild --clean

# 3. build & run on connected Android device/emulator
npx expo run:android
```

After the dev client is installed on the device once, daily dev is just:

```bash
npm start          # launches Metro (expo start --dev-client)
```

…then open the installed dev-client app on your device.

## Building a release APK

```bash
# EAS cloud build (recommended)
npm install -g eas-cli
eas login
eas build -p android --profile preview   # APK
eas build -p android --profile production # AAB

# or local build
cd android && ./gradlew assembleRelease
```

## Known limitations

- **Expo Go is NOT supported** — requires the custom dev client (due to `react-native-date-picker`). Always use `npx expo run:android` / EAS dev build.
- `react-semicircle-progressbar` is unmaintained; if it breaks on RN 0.81, swap to `react-native-circular-progress` (already installed) or keep as-is.
- The `android/` folder is regenerated on every `expo prebuild --clean`. Do NOT add custom native code directly — use Expo config plugins or the Expo modules API.

## Troubleshooting

- **Metro cache issues**: `npx expo start --dev-client -c`
- **Prebuild out of sync**: `npx expo prebuild --clean`
- **Fonts missing**: verify paths in `app.json` `expo-font` plugin match files in `assets/fonts/` and `node_modules/react-native-vector-icons/Fonts/`
- **Gradle errors after prebuild**: delete `android/.gradle/` and rebuild
